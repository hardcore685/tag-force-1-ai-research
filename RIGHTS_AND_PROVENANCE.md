# Rights and provenance

The analysis targets Konami's Yu-Gi-Oh! GX Tag Force (PSP), USA ULUS10136 v1.03.
Game names and source-derived behavior identify the research target. No
affiliation or endorsement is represented.

Generated C is mechanically translated from recovered game instructions.
Readable Python reconstructs selected routines; tooling and documentation were
prepared with AI assistance and checked against recorded evidence. These are
not recovered original source files or original developer symbols.

No blanket MIT/GPL or other license is assigned by this package. Rights in
reconstructed game code, embedded library implementations and newly authored
tooling require separate consideration. Do not infer permission for original
game content from the availability of this research source.

Third-party dependencies are not vendored in this public package. Their own
licenses apply. Background references are linked in README.md; the generated
native source retains no asserted replacement for the original rights notices.

The public bundle excludes original executable images, data/resource archives,
memory fixtures, save data, decoded card-text exports, artwork and compiled DLLs.
The private experiment ZIP is a different artifact and is not a public release.
